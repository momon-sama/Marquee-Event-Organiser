# Marquee-Event-Organiser
A full-stack front-end web app that lets users plan, customize, and promote events end-to-end. Built with React and hand-coded UI components (no component libraries), featuring a distinctive ticket-stub design system, live countdown timers, RSVP/guest management, and an integrated promotion toolkit with auto-generated social captions.
Marquee is an event management web app that covers the full lifecycle of running an event: creating it, customizing its look, filling the room, and getting the word out.

Key features:

Event creation & theming — title, category, date/time, venue, capacity, and description, with a customizable accent color and emoji sticker per event
Ticket-stub inspired UI — a distinctive card design with perforated edges and a date-badge stub, built entirely with hand-written CSS
Live countdown timer — real-time days/hours/minutes/seconds until each event
Guest management — add guests, track RSVP status (Going / Maybe / Declined), and see live capacity fill percentage
Promotion toolkit — shareable event link with one-click copy, auto-generated social media captions (with a shuffle option), and a promotion channel checklist (Instagram, email, group chat, flyer)
Search & filtering — find events by name/venue or filter by category

Tech stack: React (hooks-based state management), custom CSS with CSS variables for theming, vanilla SVG icon components (no external icon library), Google Fonts for typography.
